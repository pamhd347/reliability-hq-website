# Implementation Notes

## Kadence Theme Tips

1. **Hero Section:** Use Kadence "Row Layout" with full-width background (Deep Teal #0D6E6E or gradient). White text. Advanced Heading for headline, Text block for subheadline, Buttons block for CTAs.

2. **Pain Points:** Use "Info Box" blocks or "Icon List" blocks. Each pain point as a separate block with icon on left.

3. **Product Categories:** Use "Info Box" blocks in a 4-column row. Icons above, title, description below.

4. **How It Works:** Use "Info Box" blocks with numbered icons or Kadence "Count Up" blocks for visual interest.

5. **Email Signup:** Use Kadence Form block or embed your email provider's form (ConvertKit, Mailchimp, etc.)

6. **Featured Products:** Will integrate with WooCommerce product blocks once products are created.

## Colour Application

- **Deep Teal (#0D6E6E):** Primary buttons, hero backgrounds, headings, links
- **Slate Navy (#2C3E50):** Body text, footer background, secondary elements
- **Accent Amber (#E67E22):** Highlight CTAs, sale badges, important callouts, hover states
- **White (#FFFFFF):** Backgrounds, text on dark backgrounds
- **Light Grey (#F8F9FA):** Alternate section backgrounds for visual separation

## Typography

- **Headings (Inter):** Bold weight, slightly tighter letter-spacing
- **Body (Source Sans Pro):** Regular weight, comfortable line-height (1.6-1.7)
